# AnyModel Avatar Tools 2.5.2

Installable Blender add-on ZIP for the Blender 4.5 build target. The add-on metadata declares Blender 4.2.0 as the minimum supported version.

## Install

1. Download `AnyModel_Blender_Addon-2.5.2-Blender-4.5.zip` from the **Assets** section below.
2. In Blender, open **Edit → Preferences → Add-ons → Install from Disk…**.
3. Select the ZIP, install it, and enable **AnyModel Avatar Tools**.
4. In the 3D View, press **N** and open the **AnyModel** tab.

Do not unpack the ZIP before installing it. The Minecraft JAR is distributed separately through CurseForge and is not part of this release.
